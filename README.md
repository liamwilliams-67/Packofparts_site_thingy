# Starting on a server

### Requires node.js and npm installed on your local machine.

#### Cloning

First get into your file where you want to run the server,

```
cd path-to-your-folder
```
Then copy from the github using,
```
# Link may be diffrent depeding on the right repo
git clone https://github.com/liamwilliams-67/Packofparts_site_thingy.git
```
Then delete the .github folder

#### Starting

```
npm install
# The config files may cause issues for some servers, --force makes the site runnable (But not fixed)
npm audit fix --force
npm run dev
```

If ran correctly it should return a link to your localhost site.
